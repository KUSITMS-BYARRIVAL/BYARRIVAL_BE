# 마이 · 설정 (MY)

## 프로필

### MY-01 프로필 정보 조회 `P0`
- 설명: 사용자의 프로필 및 주요 설정 정보를 확인한다.
- 입력: 사용자 ID
- 처리: 닉네임, 프로필 이미지, 이동 유형 및 주요 설정값을 조회한다.
- 출력: 프로필 정보
- 예외: 조회 실패 시 오류 UI
- 비고: -

### MY-02 프로필 이미지 변경 `P1`
- 설명: 프로필 이미지를 촬영하거나 앨범에서 선택해 변경한다.
- 입력: 이미지 파일
- 처리: 이미지 선택 후 업로드하고 성공 시 사용자 프로필 URL을 갱신한다.
- 출력: 변경된 프로필 이미지
- 예외: 권한 거부 시 설정 이동 안내
- 비고: 사진 권한 필요

### MY-03 닉네임 변경 `P1`
- 설명: 사용자 닉네임을 수정한다.
- 입력: 닉네임
- 처리: 입력값 유효성을 검사하고 성공 시 프로필에 반영한다.
- 출력: 변경된 닉네임
- 예외: 유효하지 않으면 저장 불가
- 비고: 온보딩 유효성 규칙 재사용

### MY-11 직군 변경 `P0`
- 설명: 설정에서 직군을 변경한다.
- 입력: 직군 코드(12종) 최대 2개
- 처리: 온보딩 직군 선택(ONB-11)과 동일한 UI로 최대 2개를 선택하고, 저장 즉시 홈 내 직군 기준에 반영한다. 학생은 "희망 직군"으로 표기한다. 1개 이상 필수, 3번째 선택 시 최대 2개 안내를 노출한다. 홈 직군 칩 순서는 저장된 직군 목록 순서를 따르며, 직군을 변경하면 유지되는 직군이 앞에, 새로 추가한 직군이 뒤에 온다.
- 출력: 변경된 직군 목록(1~2개)
- 예외: 저장 실패 시 토스트 안내 후 기존 값 유지
- 비고: -

### MY-12 근무 지역 변경 `P1`
- 설명: 설정에서 근무·통학·주 이동 지역을 변경한다.
- 입력: 시/도, 시/군/구
- 처리: 온보딩 지역 선택(ONB-12)과 동일한 UI로 단일 선택하며 변경 이력을 남긴다. 이동 유형에 따라 근무/통학/주 이동 지역으로 표기한다. "○○전체" 선택지는 제공하지 않는다.
- 출력: 변경된 지역
- 예외: 저장 실패 시 토스트 안내 후 기존 값 유지
- 비고: -


## 개인 설정

### MY-04 이동 상황 변경 `P0`
- 설명: 직장인·학생·기타 유형을 변경한다.
- 입력: 이동 유형
- 처리: 사용자 유형을 갱신하고 서비스 카피에 반영한다. 진행 중 노선의 추천 결과는 유지한다.
- 출력: 이동 유형
- 예외: 저장 실패 시 기존 값 복구
- 비고: 추천 조건은 다음 노선부터 반영

### MY-05 기본 이동 시간 변경 `P0`
- 설명: 기본 이동 시간을 변경한다.
- 입력: 이동시간
- 처리: 설정값을 저장하고 이후 노선 생성 시 사용한다.
- 출력: 이동시간
- 예외: 범위 외 값 저장 불가
- 비고: 요일별 설정(MY-07)이 없는 날에 사용하는 기본값. 다음 노선부터 반영.

### MY-06 관심 분야 변경 `P0`
- 설명: 뉴스 추천 관심 분야를 변경한다.
- 입력: 카테고리 ID 목록
- 처리: 선택 카테고리를 저장하고 이후 추천 요청부터 반영한다. 카테고리는 8개 서비스 카테고리 기준이다(ONB-09, RSS-07 참조).
- 출력: 관심 분야
- 예외: 1개 미만 선택 시 저장 불가
- 비고: 최소 1개 이상 선택. 다음 노선부터 반영(진행 중 노선은 스냅샷 유지)

### MY-07 요일별 이동 시간 설정 `P0`
- 설명: 요일별 이동 시간을 개별 설정한다.
- 입력: 월~일 이동시간
- 처리: 요일별 0~120분 범위에서 5분 단위로 설정한다. 최소 하루 이상 이동일이 있어야 저장 가능하다.
- 출력: 요일별 이동시간
- 예외: 전체 요일 0분이면 저장 불가
- 비고: 0분=쉬는 날. 요일별 설정이 기본 이동시간보다 우선하며, 쉬는 날에 노선 생성을 요청하면 기본 이동시간으로 생성(RIDE-04).

## 알림

### MY-08 알림 설정 `P1`
- 설명: 이동 관련 서비스 알림의 수신 여부를 설정한다.
- 입력: 알림 유형별 ON/OFF
- 처리: 사용자 알림 설정과 OS 권한을 확인하고 수신 설정을 저장한다.
- 출력: 알림 설정
- 예외: OS 알림 OFF 시 설정 이동 안내
- 비고: 유형별 출근/등교/출발 등 카피

## 계정

### MY-09 로그아웃 `P0`
- 설명: 현재 계정의 로그인 상태를 종료한다.
- 입력: 로그아웃 확인
- 처리: 확인 후 인증 정보를 제거하고 로그인 화면으로 이동한다.
- 출력: 비로그인 상태
- 예외: 실패 시 로그인 상태 유지
- 비고: 확인 Alert

### MY-10 회원 탈퇴 `P0`
- 설명: 사용자 계정을 삭제하고 프로필·설정과 서비스 이용 이력은 정해진 기간 보관 후 파기한다.
- 입력: 사용자 ID, 탈퇴 확인
- 처리: 최종 확인 후 탈퇴 처리를 수행하고 인증 정보를 제거한다. 프로필·설정(닉네임, 이동 유형, 이동 시작 시각, 이동시간, 관심분야 등)과 서비스 이용 이력(읽음·컨디션 이력, 추천 로그, 이벤트 로그)은 탈퇴일로부터 6개월간 보관한 뒤 파기한다. 보관 기간(6개월) 내에 재가입하면 프로필·설정과 이용 이력을 모두 복원하고, 기간이 지나면 신규 가입으로 처리한다.
- 출력: 탈퇴 완료
- 예외: 실패 시 계정 유지 및 오류 안내
- 비고: 재가입 제한 없음. 복원 대상: 프로필·설정 + 이용 이력 전체. 보관 사실은 약관·개인정보처리방침에 고지가 필요하고 법무 검토 권장.

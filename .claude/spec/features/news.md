## 기사 읽기

### READ-01 기사 조회 `P0`
- 설명: 노선에 포함된 기사 콘텐츠를 제공한다.
- 입력: routeId, articleId
- 처리: 기사 제목, 언론사, AI 3줄 요약 및 원문 정보를 조회한다. 운행 화면에서 AI 3줄 요약은 기사 사진 아래에 표시한다. 시작 화면에서는 기사 제목 바로 아래에 AI 한 줄 요약(oneLine)을 표시한다.
- 출력: 기사 콘텐츠 (제목, 언론사, 사진, AI 한 줄 요약, AI 3줄 요약, 원문 정보)
- 예외: 삭제·비공개 기사면 건너뛰고 다음 기사로 이동
- 비고: RSS/AI 가공 데이터 사용

### READ-02 기사 읽기 진행 상태 `P0`
- 설명: 사용자의 기사 읽기 진행 상태를 기록한다.
- 입력: articleId, 진행 상태
- 처리: 읽기 진행 정보를 저장하고 기준 충족 시 읽음/완독 상태로 처리한다. 읽음 이력(사용자·articleId·열람일시)은 삭제하지 않고 보관하며, 추후 개인화에 활용한다. 노선 추천 후보 풀에는 사용하지 않는다(RIDE-04, 하루 기준). 운행 화면에서 [기사 보러가기]를 눌러 원문 URL로 이동하는 순간 해당 기사를 열람(완독)으로 처리하고 다음으로 넘어가는 버튼을 활성화한다. 원문 링크가 깨졌거나 열리지 않아도 '원문을 열 수 없어요' 토스트 안내 후 다음 버튼을 활성화한다(RIDE-06). 나의 기록의 '일부 완독'은 이 열람 처리를 기준으로 산출한다(STAT-02).
- 출력: 진행률, 완독 여부
- 예외: 중도 이탈 시 마지막 진행 상태 저장
- 비고: 완독 기준: [기사 보러가기]를 눌러 원문 URL로 이동하는 시점

### READ-03 다음 기사 이동 `P0`
- 설명: 현재 기사 확인 후 노선의 다음 기사로 이동한다.
- 입력: routeId, 현재 기사 순번
- 처리: 현재 기사 상태를 저장하고 다음 순번 기사를 조회한다.
- 출력: 다음 기사/도착 화면
- 예외: 마지막 기사면 도착 단계 이동
- 비고: -

### READ-04 기사 스크랩 `P1`
- 설명: 현재 기사를 보관함에 저장하거나 해제한다.
- 입력: 사용자 ID, articleId, 저장 상태
- 처리: 스크랩 데이터를 생성/삭제하고 변경 상태를 UI에 반영한다.
- 출력: 스크랩 상태
- 예외: 실패 시 UI 상태 원복
- 비고: Toggle

### READ-05 기사 원문 보기 `P1`
- 설명: 언론사에서 제공하는 원문 기사로 이동한다.
- 입력: originalUrl
- 처리: 저장된 원문 URL을 호출하여 외부 페이지를 연다.
- 출력: 원문 페이지
- 예외: URL 유효하지 않으면 기능 비활성화
- 비고: 출처 및 원문 링크 명시

### READ-06 운행 진행 정보 표시 `P1`
- 설명: 현재 노선의 진행 위치와 남은 콘텐츠 정보를 제공한다.
- 입력: routeId, 현재 순번
- 처리: 전체 기사 수와 현재 위치를 비교하여 진행률과 남은 기사를 계산하고, 남은 시간은 남은 기사의 예상 읽기시간(RSS-09) 합으로 계산한다.
- 출력: 진행률, 남은 기사, 남은 시간
- 예외: 시간 계산 불가 시 기사 수 중심 표시
- 비고: 유형별 목적지 카피

## 퀴즈

### QUIZ-01 오늘의 퀴즈 조회 `P0`
- 설명: 오늘 읽은 기사에 기반한 퀴즈를 제공한다.
- 입력: routeId, 완독 articleId
- 처리: 완독한 기사와 연결된 유효한 퀴즈를 조회해 순서대로 제공한다.
- 출력: 퀴즈 문제, 선택지
- 예외: 출제 가능한 문제 없으면 결과 화면으로 이동
- 비고: AI 생성 데이터

### QUIZ-02 퀴즈 답안 제출 `P0`
- 설명: 사용자가 선택한 답안의 정오답을 판정한다.
- 입력: quizId, answerId
- 처리: 저장된 정답과 입력값을 비교하고 결과 및 사용자 응답을 저장한다.
- 출력: 정오답, 해설
- 예외: 동일 문제 중복 제출 방지
- 비고: -

### QUIZ-03 퀴즈 결과 표시 `P1`
- 설명: 오늘의 퀴즈 결과를 종합하여 제공한다.
- 입력: 퀴즈 응답
- 처리: 전체 문제 수와 정답 수를 집계해 결과를 표시하고 기록에 반영한다.
- 출력: 정답 수, 퀴즈 결과
- 예외: 미응답 문항 처리 정책 확인
- 비고: -

## 도착

### ARR-01 노선 완주 처리 `P0`
- 설명: 마지막 기사까지 이용한 경우 오늘 노선을 완주 처리한다.
- 입력: routeId, 이용 기록
- 처리: 최종 진행 상태를 저장하고 노선 상태를 완주로 변경하며 이용 기록 및 스트릭 반영 대상으로 처리한다. 자정을 넘겨 완주해도 노선의 생성일(서비스일) 기준으로 기록한다. 완주 처리 시점은 마지막 기사 화면에서 [기사 보러가기]로 원문 URL로 이동한 뒤 활성화되는 완료 버튼(예: [도착하기])을 누르는 순간이다(제안). 원문 링크가 열리지 않아도 버튼이 활성화되므로 완주할 수 있다(READ-02).
- 출력: 완주 상태
- 예외: 저장 실패 시 재시도
- 비고: -

### ARR-02 완주 결과 표시 `P0`
- 설명: 오늘 소비한 뉴스 콘텐츠와 이용 결과를 요약한다.
- 입력: routeId
- 처리: 읽은 기사 수, 이용시간, 완주 여부 등을 집계한다.
- 출력: 완주 결과
- 예외: 집계 실패 시 기본 완료 상태 제공
- 비고: 유형별 카피

# 콘텐츠 탐색 · 기록 (LIB, PICK, STAT)

## 보관함

### LIB-01 보관 콘텐츠 조회 `P0`
- 설명: 저장한 기사·스몰토크·상식 용어를 유형별로 확인한다.
- 입력: 사용자 ID, 콘텐츠 유형
- 처리: 사용자 스크랩 데이터를 유형별로 조회하고 탭별 목록 및 개수를 제공한다.
- 출력: 저장 콘텐츠 목록
- 예외: 저장 콘텐츠 없으면 Empty UI
- 비고: 탭별 저장 개수 표시

### LIB-02 저장 기사 정렬 `P1`
- 설명: 저장한 기사를 저장 시점 기준으로 정렬한다.
- 입력: 정렬 조건
- 처리: 선택한 기준으로 목록 순서를 변경한다.
- 출력: 정렬된 목록
- 예외: -
- 비고: 최신순/오래된순

### LIB-03 저장 기사 카테고리 필터 `P1`
- 설명: 저장한 기사를 관심 분야별로 필터링한다.
- 입력: 카테고리 ID
- 처리: 해당 카테고리에 속한 저장 기사만 표시한다.
- 출력: 필터 결과
- 예외: 결과 0건이면 분야별 Empty UI
- 비고: 0건 카테고리 숨김

### LIB-04 저장 콘텐츠 삭제 `P0`
- 설명: 보관함에서 저장 콘텐츠를 삭제한다.
- 입력: 사용자 ID, 콘텐츠 ID
- 처리: 삭제 확인 후 스크랩 데이터를 삭제하고 Toast를 노출한다. 되돌리기 시 삭제 상태를 복구한다.
- 출력: 갱신 목록, Toast
- 예외: 실패 시 목록에서 제거하지 않음
- 비고: 되돌리기 제공

### LIB-05 삭제 기사 상태 표시 `P1`
- 설명: 원문이 삭제·비공개된 저장 기사를 비활성 상태로 표시한다.
- 입력: 기사 활성 상태
- 처리: 보관 기록은 유지하되 비활성 카드와 삭제 안내를 표시한다.
- 출력: 비활성 기사 카드
- 예외: 원문/상세 진입 제한
- 비고: 삭제 자체는 가능

## 스몰토크

### PICK-01 스몰토크 목록 조회 `P1`
- 설명: 제공 중인 스몰토크 콘텐츠 목록을 확인한다.
- 입력: 목록 조회 조건
- 처리: 당일(서비스일) 생성된 노출 가능 스몰토크를 조회하여 카드 목록으로 제공한다. 카드 구성: 카테고리 + 연결 뉴스 제목 / 한 줄(hook) / 이어서(followup). 카드 탭 시 상세(PICK-02) 이동, 연결 뉴스 영역 탭 시 원문으로 이동.
- 출력: 스몰토크 목록
- 예외: 콘텐츠 없으면 Empty UI. 기반 기사가 숨김·삭제된 스몰토크는 목록에서 제외.
- 비고: 생성 기준은 TALK-01 참고.

### PICK-02 스몰토크 상세 조회 `P1`
- 설명: 선택한 스몰토크의 상세 내용을 확인한다.
- 입력: 콘텐츠 ID
- 처리: 선택 스몰토크의 한 줄(hook), 이어서(followup), 연결 뉴스(카테고리·제목)를 조회한다. 연결 뉴스 영역 탭 시 기반 기사의 원문 URL을 새 창/외부 브라우저로 연다. 저장(스크랩) 버튼 제공.
- 출력: 상세 콘텐츠(hook, followup, 연결 뉴스 카테고리·제목·원문 링크)
- 예외: 삭제된 콘텐츠는 이용 불가 안내. 원문 URL 오류·접근 불가 시 "원문을 열 수 없어요" 토스트, 스몰토크 본문은 유지.
- 비고: 생성 기준은 TALK-01 참고. 화면: 오늘의 뉴스·카테고리 + 제목 칩 → 한 줄 말풍선 → 이어서 본문.

### PICK-03 스몰토크 스크랩 `P1`
- 설명: 스몰토크를 보관함에 저장하거나 해제한다.
- 입력: 사용자 ID, 콘텐츠 ID
- 처리: 사용자-콘텐츠 스크랩 데이터를 생성/삭제한다.
- 출력: 스크랩 상태
- 예외: 실패 시 기존 상태 유지
- 비고: -

## 상식 용어

### PICK-04 상식 용어 조회 `P1`
- 설명: 상식 용어 목록 및 상세 설명을 확인한다.
- 입력: 목록 조건/용어 ID
- 처리: 목록을 조회하고 선택 시 해당 용어의 정의와 설명을 제공한다.
- 출력: 용어 목록/상세
- 예외: 데이터 없으면 Empty UI
- 비고: -

### PICK-05 상식 용어 스크랩 `P1`
- 설명: 상식 용어를 보관함에 저장하거나 해제한다.
- 입력: 사용자 ID, 용어 ID
- 처리: 사용자별 스크랩 데이터를 생성/삭제한다.
- 출력: 스크랩 상태
- 예외: 실패 시 기존 상태 유지
- 비고: -

## 이용 기록

### STAT-01 이용 기록 요약 조회 `P0`
- 설명: 사용자의 기간별 뉴스 이용 기록을 요약한다.
- 입력: 사용자 ID, 조회 기간
- 처리: 총 이용시간, 읽은 기사 수, 완주 횟수 등을 기간별로 집계한다.
- 출력: 이용 통계
- 예외: 기록 없으면 Empty UI
- 비고: 주/월/전체

### STAT-02 기록 캘린더 조회 `P0`
- 설명: 날짜별 콘텐츠 이용 기록을 캘린더로 제공한다.
- 입력: 사용자 ID, 연·월
- 처리: 날짜별 읽은 기사 수와 완주 상태 등을 조회하여 단계별 상태로 표시한다.
- 출력: 캘린더 데이터
- 예외: 미래 날짜 비활성화
- 비고: 이용량 단계 표시

### STAT-03 기간별 이용 그래프 `P1`
- 설명: 최근 이용량 변화를 그래프로 확인한다.
- 입력: 사용자 ID, 기간
- 처리: 기간별 이용시간 또는 소비량을 집계해 그래프 데이터로 변환한다.
- 출력: 그래프 데이터
- 예외: 데이터 없으면 초기 안내
- 비고: 화면 기준 6주

## 어드민 공통

### ADM-01 어드민 로그인 `P0`
- 세부 그룹: 인증
- 설명: 운영진 계정의 이메일과 비밀번호를 입력하여 어드민에 로그인한다.
- 입력: 이메일, 비밀번호
- 처리: 이메일 형식 및 계정 정보를 검증한다. 인증 성공 시 계정 권한을 확인하고 어드민 메인으로 이동한다.
- 출력: 로그인 상태, 어드민 화면
- 예외: 이메일 형식 오류 시 Inline 안내. 로그인 5회 실패 시 10분간 잠금. 세션 만료 시 로그인 화면 이동
- 비고: 운영진 등록 계정만 로그인 가능

### ADM-02 어드민 권한 구분 `P2`
- 세부 그룹: 권한
- 설명: 계정 권한에 따라 접근 가능한 어드민 기능을 구분한다.
- 입력: 로그인 계정, 권한 정보
- 처리: 운영자는 전체 메뉴에 접근 가능하며, 에디터는 기사 관리·에디터 픽에만 접근 가능하도록 메뉴 및 기능 접근을 제한한다.
- 출력: 권한별 접근 가능 메뉴
- 예외: 권한 없는 메뉴 접근 시 접근 차단
- 비고: 운영자 / 에디터 2단계

## 기사 관리

### ARTICLE-01 기사 목록 조회 `P0`
- 세부 그룹: 기사 목록
- 설명: 수집된 기사와 처리 상태를 상태 탭별 표로 조회한다.
- 입력: 상태 탭, 페이지, 필터/검색 조건
- 처리: 전체/노출 중/숨김/오류 탭별 건수와 목록을 조회한다. 오류에는 수집 오류·생성 실패·원문 삭제를 포함한다. 제목, 언론사, 카테고리, 수집 시각, 처리 상태(수집·요약·퀴즈), 노출 상태, 조회 수를 표시하고 페이지 단위로 조회한다.
- 출력: 상태별 기사 수, 기사 목록
- 예외: 결과 없음 시 Empty UI. 마지막 페이지에서 다음 이동 제한
- 비고: 상태 탭에 전체 건수 표시. 페이지당 20개. (구 ARTICLE-01·07·10 통합)

### ARTICLE-02 기사 검색·필터 `P0`
- 세부 그룹: 기사 목록
- 설명: 조건에 따라 관리할 기사를 검색하고 필터링한다.
- 입력: 제목, 언론사, 카테고리, 난이도, 처리 상태, 수집일
- 처리: 입력된 검색어와 선택된 필터 조건을 조합하여 일치하는 기사만 조회한다.
- 출력: 필터링된 기사 목록
- 예외: 검색 결과가 없으면 Empty UI 및 필터 초기화 제공
- 비고: 언론사 필터는 별도 언론사 메뉴 대체 가능

### ARTICLE-03 RSS 즉시 수집 `P0`
- 세부 그룹: RSS 수집
- 설명: 정기 수집과 별개로 운영자가 RSS 기사를 즉시 수집한다.
- 입력: 수집 실행 요청
- 처리: 활성 RSS Feed를 대상으로 신규 기사를 수집하고 당일 GUID/URL 중복을 제거한다. 완료 후 신규 수집 결과를 안내한다.
- 출력: 신규 수집 기사, 수집 결과 Toast
- 예외: 수집 실패 시 실패 사유 Toast. 수집 중 버튼 Disabled 및 Spinner 표시
- 비고: 자동 수집은 매일 23:45 배치, 23:59 완료 기준

### ARTICLE-04 기사 일괄 숨김·복구 `P1`
- 세부 그룹: 일괄 작업
- 설명: 목록에서 선택한 여러 기사를 한 번에 숨기거나 복구한다.
- 입력: 선택 articleId 목록, 숨김 사유
- 처리: 숨김: 확인 및 사유 입력 후 노출 상태를 숨김으로 변경하고 이력 저장. 복구: 숨김 해제 후 노출 조건을 충족하는 기사만 다시 노출.
- 출력: 변경된 기사 상태
- 예외: 선택 기사 없으면 실행 불가. 복구 불가능 상태 기사는 제외
- 비고: 체크박스 선택 시 작업 바 노출. (구 ARTICLE-04·05 통합)

### ARTICLE-05 기사 숨김·복구 `P0`
- 세부 그룹: 노출 관리
- 설명: 개별 기사를 사유 확인 후 서비스에서 숨기거나 다시 노출한다.
- 입력: articleId, 변경 상태, 숨김 사유, 메모
- 처리: 숨김: 확인 모달에서 사유(저작권·이용 허락 문제 / 오보·정정 필요 / 품질 이슈 / 기타)를 받고 확인 시 노선·검색에서 제외, 보관함에서는 삭제된 기사로 표시, 처리 이력 저장. 복구: 숨김 해제 후 노출 조건을 다시 확인해 노출 대상으로 변경.
- 출력: 노출/숨김 상태, 처리 이력
- 예외: 사유 미선택 시 [숨기기] Disabled. 기타 선택 시 메모 필수. 복구 실패 시 오류 안내
- 비고: 목록 또는 상세에서 실행. 숨김은 모달, 복구는 숨김 상태 기사에만 제공. (구 ARTICLE-08·17·18 통합)

### ARTICLE-06 기사 재생성 `P1`
- 세부 그룹: AI 처리
- 설명: 요약 또는 퀴즈 생성에 실패한 기사의 AI 가공을 다시 실행한다.
- 입력: articleId, 실패 처리 단계
- 처리: 실패한 AI 처리 단계를 확인하여 해당 단계부터 재생성을 요청한다.
- 출력: 갱신된 처리 상태
- 예외: 최대 재시도 정책은 별도 관리
- 비고: 오류 기사 대상

### ARTICLE-07 기사 상세 조회 `P0`
- 세부 그룹: 기사 상세
- 설명: 선택한 기사의 원본 정보, AI 요약, 메타 정보, 자동 생성 퀴즈, 처리 상태를 읽기 전용으로 조회한다.
- 입력: articleId
- 처리: 기사 상태, 카테고리, 제목, 언론사, 수집/원문 확인 시각, AI 3줄 요약, 메타 정보(예상 읽기시간·핵심 키워드·퀴즈 생성 상태), 퀴즈 1문항(문제·보기·정답·생성 상태), 수집→요약→퀴즈→노출 단계 상태를 조회한다. 원문 보기는 originalUrl을 새 탭으로 연다.
- 출력: 기사 상세 정보
- 예외: 삭제된 원문(404)은 원문 확인 불가 표시 및 오류 분류. 요약·퀴즈 문제 발견 시 재생성 또는 기사 숨기기
- 비고: 읽기 전용(수정 불가). 기사당 퀴즈 1문항. (구 ARTICLE-11·12·13·14·15 통합)

### ARTICLE-08 기사 처리 이력 조회 `P2`
- 세부 그룹: 처리 이력
- 설명: 기사 수집부터 노출까지의 처리 과정을 시간 순으로 확인한다.
- 입력: articleId
- 처리: 수집 → 요약 생성 → 퀴즈 생성 → 자동 노출 단계의 상태와 시각을 조회한다. 숨김·복구 이력이 있는 경우 운영자·사유·시각을 함께 표시한다.
- 출력: 기사 처리 이력
- 예외: -
- 비고: 실패 단계는 오류 표시

## 에디터 픽

### EDITOR-01 노출일 설정 `P0`
- 세부 그룹: 노출 설정
- 설명: 에디터 픽 콘텐츠가 앱에 노출될 날짜를 설정한다.
- 입력: 노출 날짜
- 처리: 선택 날짜를 콘텐츠 노출 기준일로 저장하고 해당 날짜에 확정된 콘텐츠를 앱에 노출한다.
- 출력: 노출일
- 예외: 해당 날짜 노출 개수 0개면 앱 에디터 픽 섹션 숨김
- 비고: 기본값 내일

### EDITOR-02 AI 초안 생성 `P0`
- 세부 그룹: 콘텐츠 생성
- 설명: 노출 중인 기사를 선택해 AI 스몰토크 초안을 생성하고 필요 시 다시 생성한다.
- 입력: 노출일, 상향 라벨, 건네는 한마디, 이어서, 연결 기사
- 처리: 노출 중 기사만 선택해 에디터 픽과 연결하고, 입력값과 기사 내용으로 AI 초안을 생성해 상태를 AI 초안으로 저장한다. 재생성 시 기존 내용 삭제 확인 후 현재 내용 기준으로 다시 요청한다.
- 출력: AI 초안
- 예외: 실패 시 Toast 및 재시도. 재생성 전 기존 내용 삭제 확인 Alert. 연결 기사가 숨김 처리되면 스몰토크도 자동 숨김
- 비고: 수동 실행. 재생성은 AI 초안일 때만 노출. (구 EDITOR-03·06·07 통합)

- 출력: 신규 초안
- 예외: 필수값 누락 시 저장 불가

## 회원 관리

### MEMBER-01 회원 목록 조회 `P1`
- 세부 그룹: 회원 조회
- 설명: 가입 회원을 검색·필터하고 총 회원 수와 주요 정보를 목록으로 확인한다.
- 입력: 검색어, 유형, 가입수단, 상태, 페이지
- 처리: 조건에 일치하는 회원 목록과 총 회원 수를 조회한다. 회원번호, 닉네임, 가입수단, 유형, 가입일, 연속 기록을 표시한다.
- 출력: 필터링 회원 목록, 회원 수
- 예외: 검색 결과 없으면 Empty UI. 탈퇴 회원은 목록에서 제외
- 비고: 상태: 정상/휴면 예정/이용 제한. 이메일 등 개인정보는 마스킹. (구 MEMBER-01·02·03 통합)

### MEMBER-02 회원 상세 조회 `P1`
- 세부 그룹: 회원 상세
- 설명: 선택한 회원의 서비스 이용 및 설정 정보를 상세 조회한다.
- 입력: userId
- 처리: 가입 정보, 이동 설정, 관심 분야, 연속 기록, 이번 달 완주, 알림 수신 여부, 구독 플랜 등을 조회한다.
- 출력: 회원 상세 정보
- 예외: 개인정보 접근 이력 저장
- 비고: 획득 배지·콘텐츠 강도 등은 미표시

### MEMBER-03 회원 이용 제한 `P1`
- 세부 그룹: 운영 조치
- 설명: 운영자가 특정 회원의 서비스 이용을 일정 기간 제한한다.
- 입력: userId, 제한 기간, 사유
- 처리: 확인 후 해당 회원의 상태를 이용 제한으로 변경하고 운영 조치 이력을 저장한다.
- 출력: 회원 상태, 조치 이력
- 예외: 기간·사유 미입력 시 실행 불가
- 비고: 사유 입력 필수

### MEMBER-04 회원 정보 열람 기록 `P1`
- 세부 그룹: 보안/로그
- 설명: 운영자의 회원 상세 정보 열람 이력을 기록한다.
- 입력: 운영자 ID, userId, 열람 시각
- 처리: 회원 상세 화면 진입 시 운영자와 대상 회원, 시각을 로그로 저장한다.
- 출력: 열람 로그
- 예외: -
- 비고: 개인정보 접근 기록

## 알림 · 공지

### NOTI-01 알림 작성·발송 `P1`
- 세부 그룹: 알림 작성
- 설명: 알림 유형·수신 대상·제목/본문·이동 화면·발송 시점을 설정해 발송한다.
- 입력: 알림 유형(공지·이벤트), 사용자 유형, 제목, 본문, 이동 화면(URL/화면 ID), 즉시/예약 및 예약 시각
- 처리: 입력값을 검증해 저장하고 예상 수신자를 조회한다. 최종 확인 Alert(예상 인원) 후 대상 사용자의 알림 동의 여부를 확인해 즉시 발송 또는 예약한다. 이동 화면에 맞는 딥링크를 생성해 연결한다.
- 출력: 발송/예약 결과, 예상 인원
- 예외: 대상 0명이면 발송 제한. 제목 20자·본문 60자 초과 시 입력 제한. 잘못된 이동 정보는 저장 제한. 예약 시각이 과거면 저장 불가. 발송 실패 시 실패 상태 기록
- 비고: 이벤트 선택 시 제목에 광고 자동 표시. 광고성 알림은 21~08시 야간 수신 동의자만. 점검 안내는 개발 측 처리(유형에서 제외). 대상: 전체/직장인/학생/기타. (구 NOTI-01~05·07 통합)

### NOTI-02 테스트 발송 `P1`
- 세부 그룹: 발송
- 설명: 실제 사용자 발송 전 운영자 기기로 알림을 테스트한다.
- 입력: 작성 중 알림 데이터
- 처리: 현재 입력값을 운영자 테스트 기기로 발송한다.
- 출력: 테스트 알림
- 예외: 테스트 실패 시 오류 안내
- 비고: -

### NOTI-03 알림 미리보기 `P2`
- 세부 그룹: 미리보기
- 설명: 작성 중인 알림을 실제 Push 형태로 미리 확인한다.
- 입력: 제목, 본문, 유형
- 처리: 입력 내용을 Push UI 형태로 실시간 표시한다.
- 출력: 알림 미리보기
- 예외: -
- 비고: 실시간 반영

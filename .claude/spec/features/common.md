## 인증/진입

### C-01 앱 진입 및 인증 상태 확인 `P0`
- 설명: 앱 진입 시 사용자의 로그인 및 온보딩 완료 여부를 확인한다.
- 입력: 인증 정보, 온보딩 완료 여부
- 처리: 인증이 유효하면 사용자 정보를 조회한다. 온보딩 완료 시 홈, 미완료 시 미완료 단계, 인증 정보가 없거나 만료된 경우 로그인 화면으로 이동한다.
- 출력: 홈/온보딩/로그인 화면
- 예외: 인증 조회 실패 시 로그인 화면 이동 및 오류 안내
- 비고: 최초 진입 시 실행

### C-09 로그인 만료 처리 `P0`
- 설명: 서비스 이용 중 인증이 만료되면 재로그인을 유도한다.
- 입력: 인증 만료 응답
- 처리: 로그인 만료 안내 후 로그인 화면으로 이동한다. 재로그인 성공 시 저장된 진행 상태를 복원한다.
- 출력: 로그인/복원 화면
- 예외: 재로그인 실패 시 로그인 화면 유지
- 비고: 진행 노선 서버 상태 유지

## 요청 상태

### C-03 CTA 중복 요청 방지 `P0`
- 설명: 서버 요청이 발생하는 CTA의 중복 실행을 방지한다.
- 입력: CTA 클릭, 요청 상태
- 처리: 최초 클릭 후 Loading/Disabled 상태로 전환하고 응답 전 추가 요청을 차단한다. 응답 후 상태를 해제한다.
- 출력: CTA 상태
- 예외: 요청 실패 시 CTA 재활성화
- 비고: 요청 CTA 공통

## 오류 처리

### C-06 네트워크 조회 오류 처리 `P0`
- 설명: 데이터 조회 중 네트워크 오류가 발생한 경우 재시도 기능을 제공한다.
- 입력: 네트워크 오류
- 처리: 일부 영역 실패 시 Inline 오류와 다시 시도를 제공하고 전체 데이터 실패 시 Full Screen 오류를 노출한다.
- 출력: 오류 UI, 다시 시도 CTA
- 예외: 전체 조회 실패 시 Full Screen 오류
- 비고: 영역 오류 우선

### C-07 저장·전송 오류 처리 `P0`
- 설명: 사용자 데이터 저장 또는 전송 실패 시 오류를 안내한다.
- 입력: 저장 요청 결과
- 처리: 실패 시 입력값을 유지하고 오류 Toast를 제공한다. 즉시 변경된 UI는 필요 시 이전 상태로 복구한다.
- 출력: 오류 Toast
- 예외: 필요 시 UI를 기존 상태로 Rollback
- 비고: 입력값 유지 원칙

### C-08 서버 오류 처리 `P0`
- 설명: 서버 5xx 또는 Timeout 발생 시 공통 오류 안내를 제공한다.
- 입력: 서버 응답
- 처리: 서버 오류를 감지하면 일시적 오류 안내를 제공하고 필요한 경우 재시도를 허용한다.
- 출력: 오류 Alert
- 예외: -
- 비고: -

## 로그

### LOG-01 이용 이벤트 기록 `P0`
- 설명: 기사 열람과 노선 완주 이벤트를 기록한다.
- 입력: userId, routeId, articleId, 이벤트 유형(기사 열람/노선 완주), 발생 시각
- 처리: 기사 열람(READ-01)과 노선 완주(ARR-01) 시점에 이벤트를 저장한다. 기사 열람은 완독으로 처리한다(READ-02). 중도 이탈은 별도 이벤트 없이, 노선이 완주되지 않은 채 만료(EXPIRED)된 기록으로 산출한다. 노스스타 지표(주간 완주일수)와 추천 품질 분석에 사용한다.
- 출력: 이벤트 로그
- 예외: 저장 실패 시 사용자 흐름은 막지 않고 재시도
- 비고: 중복 방지 키(제안): userId + routeId + articleId + 이벤트 유형당 1회 기록. 로그 보관 기간 6개월(경과분 파기, 확정). 읽음·컨디션 이력은 로그와 별도로 보관.

## 화면 전용 (서버 작업 거의 없음)

### C-02 공통 뒤로가기 `P1`
- 처리: 일반 화면은 직전 화면으로 이동하며 저장 확인이 필요한 화면은 Alert 확인 후 이동한다.
- 예외: 저장되지 않은 변경사항이 있으면 확인 Alert 노출

### C-04 조회 로딩 상태 `P1`
- 처리: 조회 시작 시 Skeleton을 노출하고 데이터 수신 완료 시 실제 콘텐츠로 교체한다.
- 예외: 장시간 응답 없을 경우 오류 상태 전환

### C-05 빈 상태 표시 `P1`
- 처리: 조회 결과 0건이면 데이터 유형에 맞는 안내 문구와 필요한 경우 관련 CTA를 노출한다.

### C-10 Toast 메시지 `P1`
- 처리: 결과에 맞는 메시지를 일정 시간 노출한다. 복구 가능한 액션에는 되돌리기를 제공한다.

### C-11 확인 Alert `P1`
- 처리: 취소/확인 버튼을 제공하고 확인 선택 시에만 실제 액션을 수행한다.

### C-12 BottomSheet `P1`
- 처리: 기능별 단일/복수 선택 정책에 따라 옵션을 제공하고 완료 시 선택값을 반영한다.

### C-13 외부 링크 이동 `P1`
- 입력: URL
- 처리: URL 유효성 확인 후 지정 방식으로 페이지를 연다.
- 예외: 유효하지 않은 URL은 이동 차단
- 비고: WebView/브라우저 방식 확인
